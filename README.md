## Описание репозитория:  

**hometask1 — Калькуляторы**
Программа на Python показывает, как одну задачу можно решить разными способами. Здесь представлены четыре варианта калькулятора: от последовательного набора команд и отдельных функций до универсальной функции с циклом и решения на основе класса.

**hometask2 — Работа со строками**
Интерактивная игра знакомит с основами обработки текста в Python. На пяти уровнях пользователь меняет регистр, находит и заменяет символы, а затем работает с «умным» редактором, который приводит текст в порядок: убирает лишние пробелы и корректно расставляет знаки препинания.

**hometask3 — Лабиринт**
Текстовая игра, где нужно исследовать комнаты, собирать предметы, найти ключ и выбраться наружу. На пути встречаются монстры и ловушки, а карта постепенно раскрывает уже посещённые места. В игре есть здоровье и рюкзак для хранения, сортировки, выбрасывания и комбинирования предметов. На примере инвентаря также показана работа со списками и копиями данных.

**hometask4 — Титаник**
Практическая работа по анализу данных на Python с помощью Pandas и NumPy. Скрипт загружает и изучает датасет, обрабатывает пропуски, фильтрует и группирует записи, а затем выводит статистику выживаемости пассажиров по классам, полу и портам. Очищенные данные сохраняются в отдельные CSV-файлы.
